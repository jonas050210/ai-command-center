# AI Command Center

**Local-first AI workspace** — premium chat + Ollama runtime + Model Center, with strict **€0 cost protection** enforced in the backend before any provider request is ever made.

Built for: Windows 11 · Intel i7-12700F · RTX 4060 Ti 8GB · 32GB RAM · Python 3.11.9 · Node.js 22 (works on Linux/macOS too).

---

## What works today (Phases 1–3, fully implemented, tests passing)

| Area | Capabilities |
|---|---|
| **Chat (Phase 2)** | New conversation, history, search, rename, delete, archive, pin, favorites, **real SSE streaming from Ollama**, stop generation, retry, regenerate, copy, markdown + GFM tables, syntax-highlighted code with per-block copy, model selector, per-chat system prompt, global custom instructions, token counters (exact/estimated), context-usage meter, clear error states, automatic conversation titles (generated by your local model) |
| **Ollama** | Detection: running / unavailable / connection error · installed-model discovery · context length + capabilities from `/api/show` · real streaming chat · safe pull & delete · measured speed tests |
| **Model Center (Phase 3)** | Live catalog (name, provider, local/cloud, availability, capabilities, context length, size, parameters, quantization, measured tok/s, token usage, €0.00 cost, status), 10 categories (General · Reasoning · Coding · Research · Vision · Creative · Fast · Local · Free · Experimental), search, filters, sorting, favorites, recently used, model selection, speed testing, pull with live progress, delete. Unknown values are shown as **Unknown** — nothing is faked |
| **Token tracking** | Input / output / total — always labeled **exact** (from Ollama counters) or **estimated** (heuristic). Per message, conversation, model card and session. Per-model ledger prepared for Team Mode |
| **€0 CostGuard** | `FREE_ONLY=true`, `MAX_SPEND=0.00` by default. Paid requests are **blocked server-side before any network call**, with the exact message: *"Paid model blocked. Free-only mode is enabled. No money was spent."* Tested against request-body bypass attempts. No automatic paid fallback exists |
| **Security foundation** | Fernet-encrypted provider credentials (key in `data/secret.key`, chmod 600, or `AI_CC_SECRET_KEY`), workspace path-containment sandbox (blocks `../` and `..\\` escapes), deny-by-default permission policy, tool execution audit log, localhost binding |

**Honestly marked NOT IMPLEMENTED** (HTTP 501 at their API boundaries, badges in the UI): Agent Mode · Team Mode · Research Mode · Projects · Git/GitHub integration. Their database tables and module boundaries already exist, so they integrate cleanly later.

## Quick start

```bash
# 1. one-time setup (venv + backend deps + frontend build + .env)
python setup.py

# 2. install Ollama  →  https://ollama.com/download
#    Windows:  winget install Ollama.Ollama
#    then pull the default model (configurable, see .env):
ollama pull qwen3:0.6b

# 3. start
python start.py          # → http://127.0.0.1:8000
```

`python test_overall.py` runs all four required suites: backend tests → frontend type checking → frontend production build → end-to-end system tests.

## Configuration (`.env`)

| Variable | Default | Meaning |
|---|---|---|
| `HOST` / `PORT` | `127.0.0.1` / `8000` | local-first binding |
| `OLLAMA_HOST` | `http://localhost:11434` | runtime location |
| `DEFAULT_MODEL` | `qwen3:0.6b` | **single source of truth** — nothing is hardcoded |
| `OLLAMA_NUM_CTX` | `8192` | tokens; comfortable for 8GB VRAM (4096 = lighter) |
| `OLLAMA_KEEP_ALIVE` | `10m` | keeps the model hot in VRAM |
| `FREE_ONLY` | `true` | hard block on any non-€0.00 model |
| `MAX_SPEND` | `0.00` | lifetime EUR budget |
| `DATA_DIR` | `./data` | SQLite, logs, encrypted key, workspace |
| `LOG_LEVEL` | `INFO` | JSON logs at `data/logs/app.log` |

FREE_ONLY / MAX_SPEND / default model / num_ctx / custom instructions can also be changed at runtime (Settings drawer) — persisted in SQLite, **enforced only in the backend**.

## Architecture

```
ai-command-center/
├── main.py                 # entry point (uvicorn)
├── start.py                # cross-platform launcher (uses .venv if present)
├── setup.py                # idempotent first-run setup
├── test_overall.py         # 4-suite system test (backend, ts-check, build, e2e)
├── requirements.txt · pytest.ini · .env.example · ROADMAP
├── backend/app/
│   ├── config.py           # Settings (env/.env) — single source of truth
│   ├── main.py             # app factory + composition root (Services)
│   ├── core/errors.py      # one error shape for every API error
│   ├── db/                 # aiosqlite · migrations · repositories
│   ├── providers/          # base ABC · ollama · registry   ← provider boundary
│   ├── services/           # model_router · cost_guard · chat · models · settings · tokens
│   ├── routers/            # health · system · settings · costs · providers
│   │                       # models · conversations · chat (SSE) · future (501)
│   ├── security/           # crypto vault · permission policy
│   ├── workspace/          # path-containment sandbox
│   ├── tools/              # execution audit logging
│   ├── observability/      # JSON logging · session metrics
│   └── agent/ team/ research/ gitops/   ← future-phase boundaries (501, no fakes)
├── frontend/               # React 18 · TypeScript (strict) · Vite · Tailwind v4
│   └── src/                # store · api (REST + SSE) · components
└── tests/                  # 75 pytest tests
```

**Data flow (chat):** request → ModelRouter (explicit provider › synced catalog › default provider; *no cross-provider fallback*) → **CostGuard** (blocks paid/budget-breakers pre-network) → persist user message → stream from provider (NDJSON→SSE) → persist assistant message with exact counts → usage ledger → conversation + model totals → session metrics.

## Database (SQLite, migration-managed)

`conversations · messages · models · providers · projects · tasks · teams · team_members · usage_events (tokens+costs) · files · executions · research · settings · credentials · schema_migrations` — Team-Mode-ready: `usage_events` carries `team_id`/`team_member_id`, and `team_members` carries per-model token counters from day one.

## API summary

`GET /api/health` · `GET /api/system/status` · `GET|PUT /api/settings` · `GET /api/costs` · `GET /api/usage/tokens` · `GET /api/providers` · `GET /api/models` (+`?q=category=sort=favorites=`) · `POST /api/models/refresh|test|pull(SSE)` · `POST /api/models/{p}/{n}/favorite` · `DELETE /api/models/{p}/{n}` · `GET|POST|PATCH|DELETE /api/conversations[/{id}]` · `POST /api/chat/completions (SSE)` · `POST /api/chat/regenerate (SSE)` · `POST /api/chat/stop` · `/api/agent|/api/team|/api/research|/api/git → 501`. Interactive docs at `/api/docs`.

## Hardware notes (RTX 4060 Ti 8GB)

- GPU: `qwen3:0.6b` is instant; 4B–8B models (e.g. `qwen3:4b`, `llama3.1:8b`) are the quality sweet spot on 8GB VRAM.
- `num_ctx` 8192 default; drop to 4096 for 7B+ models if VRAM tightens.
- `keep_alive=10m` avoids reload latency between messages.

## Troubleshooting

- **"Ollama unavailable"** — install & start Ollama, then Model Center → *Refresh*. Verify with `curl http://localhost:11434/api/version`.
- **Nothing in Model Center** — press *Refresh* (live discovery) or *Pull* the default model.
- **Frontend missing** — `python setup.py` builds it (needs Node 22/npm 10).
